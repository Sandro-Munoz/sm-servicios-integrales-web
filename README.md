# SM Servicios Integrales SpA — Sitio corporativo V2

Sitio HTML estático para GitHub y Cloudflare Pages.

## Publicación
Subir **todos los archivos de esta carpeta** al nivel raíz del repositorio `Sandro-Munoz/sm-servicios-integrales-web`. Reemplazar `index.html` y `logo-sm.jpg` existentes. Los archivos `.webp` deben quedar en la misma carpeta que `index.html` (no dentro de otra carpeta). Cloudflare Pages implementará automáticamente desde la rama `main`.

## Contenido
Afiches ilustrativos por servicio. No se deben presentar como fotografías verificadas de trabajos terminados. Algunos banners conservan logotipos de campañas anteriores; el encabezado usa el logotipo oficial. Revisar mensajes promocionales, garantías y marcas antes de difundir.

## Configuración Pages
Framework: None. Build command: vacío. Build output directory: raíz `/`.
